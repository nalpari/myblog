  1. JavaScript Proxy 객체의 힘

    속성 읽기, 쓰기, in 검사를 실제로 일어나기 전에 가로채는 Proxy. get, set, has 트랩과 유효성 검사, 기본값, 메모이제이션, 로깅 사례를 코드로 봅니다.

    const user = new Proxy({}, {
  set(target, property, value) {
    if (property === 'age' && typeof value !== 'number') {
      throw new TypeError('나이는 숫자여야 합니다');
    }
    target[property] = value;
    return true;   // 할당 성공
  }
});

user.age = 25;    // 통과
user.age = '25';  // TypeError
  2. Git worktree 완벽 가이드

    feature 브랜치 작업 중 main 핫픽스가 터지면 stash 대신 디렉토리를 하나 더 엽니다. 원리, 기본 명령, 실전 시나리오, bare 저장소 패턴까지.

    -git stash
-git checkout main
-git checkout -b hotfix/critical-bug
-# ...수정하고 커밋...
-git checkout feature/new-api
-git stash pop
+git worktree add ../my-project-hotfix \
+  -b hotfix/critical-bug main
+cd ../my-project-hotfix
+# feature 브랜치는 그대로. 작업 디렉토리만 하나 더 생겼다.
  3. Prisma ORM 완전 정복

    SQL 없이 타입이 맞는 쿼리, 스키마 파일 하나에서 나오는 마이그레이션과 클라이언트. Next.js App Router에서 Prisma를 세팅하고 CRUD, 트랜잭션, 타입 활용까지 정리합니다.

    import { PrismaClient } from '@prisma/client'

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined
}

// 핫 리로드마다 새로 만들지 않도록 전역에 하나만 둔다
export const prisma =
  globalForPrisma.prisma ?? new PrismaClient()

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma
}
